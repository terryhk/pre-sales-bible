# 附录A：售前工程师实战必备全流程 Checklist 总表

> **【使用说明】**  
> 本总表系统化提炼并凝结了全书 57 讲中最核心的实战检查准则，覆盖企业级大单从“商机初筛”到“技术评估”、“招投标”、“签约交付”乃至“维保增购”的全生命周期。建议主战售前在进入各个关键节点前打印并逐项打勾自检，构筑全流程零缺陷的质量防火墙。

---

## 模块一：建立需求与商机初筛阶段 Checklist

### 1.1 商机真实性与“6看尽调”核查表（对应第14~15讲）
- [ ] **看真实背景**：该项目是业务痛点驱动、政策硬性要求，还是仅仅为了向上应付的“虚假立项”？
- [ ] **看预算出处**：该项目是否已进入客户本年度正式财务预算池或政府专项债？预算额度与审批编号是否明确？
- [ ] **看决策链条**：是否已清晰定位经济决策人（Sponsor）与技术一把手（CIO/CTO）？是否具备直接或间接对话通道？
- [ ] **看竞争格局**：是否有主要友商提前半年介入？客户是否已在私下起草倾向性技术参数？
- [ ] **看实施可行性**：客户要求的上线工期是否违背软件工程基本规律？我司自研产品成熟度是否达到70%以上？
- [ ] **看沉没成本红线**：若该商机赢率预估低于 30%，是否已果断向销售及管理层提出“止损弃赛（No-Go）”建议？

### 1.2 关键干系人与 Champion 联盟核查表（对应第19~21讲）
- [ ] **干系人全息归类**：是否已按照“支持者、中立者、阻碍者、决策者”四象限完成客户关键人员全息画像？
- [ ] **Champion 真实度核验**：我方发展的内部支持者是否真正愿意为我方承担政治风险？是否愿意提供排他性独家情报？
- [ ] **暗线保护机制**：是否在公开会议中严格公事公办、严禁暴露与 Champion 的私下交往？
- [ ] **高维赋能对齐**：本周我为 Champion 输送的前沿洞察、汇报材料与行业报告数量，是否远远大于向其索取的情报？

### 1.3 独特卖点（USP）与SPIN设计核查表（对应第22~23讲）
- [ ] **USP 唯一性穿透**：提炼的 1~2 个核心卖点，是否真正满足“客户高度在意 + 我方绝对独占 + 友商难以复制”？
- [ ] **SPIN 提问链条闭环**：是否已设计好由现状问题（S）引出隐形痛点（P）、层层推演扩大后果严重性（I）、最终让客户亲口说出价值需求（N）的提问脚本？

## 模块二：技术评估与方案攻防阶段 Checklist

### 2.1 战前心理建设与红布信仰核查表（对应第29讲）
- [ ] **卸下缺陷内耗**：我是否已将注意力从产品的次要Bug彻底切换到“特定场景下的核心赋能与USP”？
- [ ] **确定性气场锚定**：在走进客户会议室前，我是否坚信我带来的方案是客户在当前约束条件下的最优解？
- [ ] **兜底预案备妥**：面对我方系统最脆弱的性能指标，我是否已准备好合理解释与工程补偿措施？

### 2.2 技术交流 PPT 与版面设计核查表（对应第30~31讲）
- [ ] **拒绝一份PPT打天下**：本胶片是否针对今天这间屋子里的关键拍板人做了30%以上的深度场景定制？
- [ ] **Storyline 标题串讲自检**：切换到大纲视图，只读每页PPT标题，是否构成一篇因果严密、层层递进的完整论断长文？
- [ ] **FAB 利益转换过滤**：通篇是否已消灭纯技术黑话？每一项 Feature 后面是否都紧跟了“这意味着（A）”与“为您带来（B）”？
- [ ] **排版八大禁忌排查**：单页主色系不超过3种、留白率超30%、无动画切换、无模糊图片、无外部软链接。
- [ ] **狡兔三窟容灾备份**：胶片文件是否已同步备份至：① 公司企业邮箱；② 随身物理U盘；③ 私人邮箱；④ 同行销售手机与电脑。

### 2.3 现场控场与硬件行装核查表（对应第32、56讲）
- [ ] **随身背包九件套清点**：多功能扩展坞（HDMI/VGA）、激光翻页笔（备用电池）、双卡5G MIFI、加密U盘、金属签字笔、降噪耳机、润喉糖。
- [ ] **生理自救就绪**：登台前是否已完成 3 次“吸4秒-呼6秒”深腹式呼吸？手中是否握有签字笔以转移紧张能量？
- [ ] **Q&A 控场规则预告**：若参会人数超10人且存在刺头，开场是否已声明“讲完全文后统一提问”？

### 2.4 产品演示（Demo）与墨菲定律防御核查表（对应第37~38讲）
- [ ] **数据本土化脱敏**：演示系统中的组织架构、账号、业务商品是否已全部替换为客户真实企业名称（坚决杜绝“张三/test”）？
- [ ] **高潮前置编排**：前3分钟内是否已端出杀手级“硬菜”（核心USP可视化直击痛点）？
- [ ] **第一道防线（脱机闭环）**：本地轻量化 Docker/虚拟机镜像是否已在完全断网（拔掉网线+关闭WiFi）状态下跑通？
- [ ] **第二道防线（一键快照重置）**：是否在演示前夜打好 Golden Snapshot 快照，并备妥一键数据重置 Shell 脚本？
- [ ] **第三道防线（终极录屏保命）**：本地桌面是否存放了 4K 超清、无剪辑、带时间戳的端到端全流程操作录屏？

### 2.5 概念验证（POC）准入“三确认”核查表（对应第40讲）
- [ ] **测试计划确认**：客户测试组长是否以正式邮件批准了我方提交的测试用例清单与时间表？
- [ ] **测试环境就绪确认**：客户是否已正式书面确认服务器、网络拓扑、存储与测试脱敏数据已全部到位？
- [ ] **专人配合确认**：客户业务及科技部门是否已正式指定对口人员名单，承诺全程现场协同打卡？
- [ ] **USP 场景植入**：测试用例中除客户要求的场景外，是否已成功植入至少 2 个体现我方杀手级优势的极端压力场景？

### 2.6 高层“电梯汇报”一页纸决策看板核查表（对应第41讲）
- [ ] **180秒叙事架构**：结论先行（量化业务回报30秒）-> 三大支撑支柱（场景/实测/交付2分钟）-> 明确行动号召（30秒）。
- [ ] **红绿灯矩阵呈现**：是否制作了一页纸 One-Pager 看板？我方是否呈现全绿领先、竞品在核心项上呈现刺眼红灯？

## 模块三：招投标、SOW 与成本测算阶段 Checklist

### 3.1 招标文件通读与废标红线排查表（对应第44~45讲）
- [ ] **时间截点死线锁定**：答疑澄清截止时间、保证金缴纳截止时间、投标文件递交截止时间是否全部录入日历预警？
- [ ] **“★”号实质性条款梳理**：标书中带有星号、加粗、或明确标为“实质性响应”的条款，是否单独汇总成《一票否决清单》？
- [ ] **排他性暗雷排查**：是否发现友商指向性专有参数？是否已在法定期限内起草并提交了专业的《答疑澄清申请函》？
- [ ] **CA数字证书有效性**：主副投标CA锁是否已插入测试机测试？证书是否在有效年检期内？

### 3.2 投标特战队倒排日历与分工核查表（对应第46讲）
- [ ] **五位一体分工明确**：投标项目经理（总控）、客户经理（商务）、售前专家（技术方案）、交付专家（SOW/成本）、商务专员（排版资质）。
- [ ] **D-4 终稿内容绝对冻结**：截标前4天是否坚决执行“内容绝对冻结”，严禁任何临时推倒重写架构的冲动？
- [ ] **D-1 强制机动缓冲期**：截标前24小时是否已完成全套标书的印刷、装订、盖章与封箱？当晚是否全员强制休息？

### 3.3 点对点应答与偏离表编制核查表（对应第47讲）
- [ ] **无一遗漏逐条编号**：技术点对点应答是否100%覆盖招标需求书，无跳号、无漏项？
- [ ] **带解释性完全满足**：对含糊或有暗雷的条款，是否严格按照“应答完全满足 + 界定技术标准 + 明确服务边界 + 设定顺延上限”进行撰写？
- [ ] **正偏离加分项对齐**：超出招标要求的高光优势项，是否已填入《技术规格正偏离表》申请加分？

### 3.4 标书技术方案防 Copy-Paste 排雷核查表（对应第48讲）
- [ ] **大纲镜像对齐评分表**：技术方案的二级、三级标题是否直接镜像映射《评分标准细则》的编号与分值？
- [ ] **全卷地毯式搜索排雷**：按下 `Ctrl+F`，是否已针对：① 前任客户简称；② 竞争对手品牌；③ Word“错误！未定义书签”；④ 通用占位符（如“XX公司”）进行全卷搜索并确认为 0 处？
- [ ] **技术与商务清单一致**：技术方案中的服务器配置清单，是否与商务报价表中的规格数量完全一致？

### 3.5 SOW 工作说明书法律边界核查表（对应第49讲）
- [ ] **Out-of-Scope 独立成章**：是否白纸黑字独立设立了《工作范围不包含内容》专章？是否已明确排除历史脏数据清洗、老旧接口代码改造、第三方商业软件授权费？
- [ ] **消灭含糊动词**：“负责到底、全面协助、直到满意”等模糊承诺是否已全部替换为可量化的工时、标准接口文档与具体成果物？
- [ ] **逾期默示认可规则**：是否明确约定“甲方在收到成果物后 5 个工作日内出具书面意见，逾期未提出书面异议视为验收通过”？
- [ ] **需求变更控制闸门**：是否明确约定“超出范围必须走变更单（CR），按人天单价追加费用并顺延工期”？

### 3.6 全要素成本与工期精密测算核查表（对应第50讲）
- [ ] **WBS 人天三点估算**：是否已采用 PERT 公式基于 WBS 结构精算各岗位人月？
- [ ] **外采供应链背对背锁价**：硬件设备与第三方授权代理商给出的报价单，有效保护期是否覆盖投标及签约周期（至少90天）？
- [ ] **隐性成本全量计提**：异地驻场差旅费、13%与6%增值税税率差、质保金资金占用利息是否全量计入成本表？
- [ ] **风险准备金刚性保留**：成本表中是否独立计提了 5%~10% 的《风险应急准备金》，且未被销售抹零？
- [ ] **三级商务报价阶梯明确**：是否为销售输出了冲高价（Ceiling）、目标价（Target）与保本底价（Floor）三级方案？

### 3.7 封标、盖章与最后一公里提交核查表（对应第51讲）
- [ ] **Executive Summary 扉页置顶**：标书最前页是否插入了1页纸的《方案核心优势总结》，直接供评委抄录评审意见？
- [ ] **正本亲笔手写签名**：投标函、报价表、授权委托书正本是否全部由法定代表人或授权代表亲笔签名（严禁签名章）？
- [ ] **报价大写金额无误**：开标一览表中的大写与小写金额是否绝对一致？
- [ ] **密封骑缝章全覆盖**：文件箱所有开口缝隙是否全部覆盖易碎密封条？公章是否跨越密封条与箱体加盖？
- [ ] **随身防翻车公文包**：授权代表本人身份证原件（坚决杜绝误封入箱内！）、备用法人授权委托书（带公章）、备用公章与印泥、加密电子U盘。
- [ ] **异地提前一天入驻**：跨城市投标团队是否已在截标日前一天下午入住开标会场 1 公里内的酒店？电子标是否已提前 1 小时上传完毕？

## 模块四：决胜评标、签约交付与维保增购阶段 Checklist

### 4.1 现场述标与专家答辩核查表（对应第52讲）
- [ ] **黄金15分钟演练**：述标PPT是否已在 12 分钟内演练完毕？是否做到了前3分钟直击痛点、中间8分钟亮出硬核USP、后4分钟宣读交付保底承诺？
- [ ] **答辩柔和缓冲公式**：面对专家苛刻挑刺，是否做到开局先肯定专家深度、随之精准引用原标书页码佐证？
- [ ] **严守实质性变更底线**：现场答辩与出具书面澄清函时，是否严格守住不改变报价、不改变产品型号的法律红线？

### 4.2 商务谈判与盟友致谢核查表（对应第53讲）
- [ ] **谈判唱好红白脸**：销售负责在账期上给面子，售前是否死守住 SOW 工作范围与违约赔偿上限？
- [ ] **致谢信闭门递送**：签单后 48 小时内，是否已通过私密合规途径向背后的 Champion 呈递了真挚走心的专业致谢信？
- [ ] **启动大会推介归功**：在项目启动大会的官方致辞中，是否已将方案亮点归功于客户团队的指导？

### 4.3 项目交付交接（Handover）核查表（对应第54讲）
- [ ] **四维白皮书交接**：是否已向项目经理移交全套资产：① 商务与合同；② 技术与测试底稿；③ 干系人政治雷达与暗桩图谱；④ 非标准口头承诺清单。
- [ ] **内部三方签字备忘**：售前、项目经理、销售是否在《项目交接备忘录》上亲笔签字留档？
- [ ] **客户现场隆重托举**：开工启动会上，售前总监是否亲自到场并隆重推介项目经理，完成信任交棒？
- [ ] **首月双周顾问护航**：项目进场前 30 天，售前是否保持每周与项目经理复盘，协助化解初期争议？

### 4.4 维保运营与二三期商机催化核查表（对应第55讲）
- [ ] **月度工单商机过滤**：是否每月与现场运维负责人复盘工单，从业务抱怨与性能慢查询中提炼扩容商机？
- [ ] **半年度深度健康体检**：过去 6 个月内，是否向客户科技高层正式呈递了《系统运行健康与容量趋势评估白皮书》？
- [ ] **前瞻主导二期立项**：是否已协助客户 Champion 起草二期立项请示，并准备了《系统一致性与单一来源采购论证方案》？
